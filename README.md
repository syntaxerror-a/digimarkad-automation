# ⚡ DIGIMARKAD Automation Platform

> Free, AI-powered digital marketing automation suite — hosted on GitHub Pages, zero server costs.

**Live Demo:** [digimarkad.github.io/digimarkad-automation](https://digimarkad.github.io/digimarkad-automation)  
**Website:** [digimarkad.com](https://digimarkad.com)

---

## 7 Automation Modules

| Module | Automates |
|--------|-----------|
| 🎬 Content & Video | YouTube/Reel/TikTok scripts, captions, image prompts, content calendars |
| 📱 Social Media | Post scheduling queue, hashtag strategy, post performance analyzer |
| 🔍 SEO | Keyword research, on-page briefs, site audits, daily URL submissions |
| 👥 Lead Generation | ICP strategy, outreach sequences, lead CRM, BANT scoring |
| 📧 Email Campaigns | Drip sequences, subject lines, newsletters, 10+ templates |
| 📊 Analytics | Client reports, data insights, competitor analysis, ROI calculator |
| 🏢 Client Manager | Client CRM, 90-day strategies, proposal generator |

## Tech Stack

- **Frontend:** React 18 (no build step — runs directly in browser)
- **AI Engine:** Claude Sonnet (Anthropic API)
- **Hosting:** GitHub Pages (free)
- **Deployment:** GitHub Actions (automated)
- **Dependencies:** Zero npm packages required
